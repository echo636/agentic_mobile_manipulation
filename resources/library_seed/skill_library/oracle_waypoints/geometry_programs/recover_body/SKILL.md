# recover_body

User-saved R1Pro whole-body recovery: the measured final torso and BOTH arms, independent of which hand is occupied. Reference has right arm folded, left arm lowered and torso about2.34deg from vertical; it is not mirrored. Call with parameters={} or optional control_steps (positive integer duration estimate). Emits one Pose phase: arm=both, goal.joint_positions_rad=all18 torso/arm joints, gripper=hold, contact_target=null. cuRobo jointly plans from measured state with current full-scale payloads in either/both hands, locks base and fingers, checks complete timing and dense collision samples, then executes the full path open loop and verifies all18 joints and retention. Keep both actual gripper commands; no historical world base coordinate, object identity, simulator reset or trajectory replay. This explicit calibrated robot-joint reference may be reused without recomputing its target for each scene; current obstacles, mechanical limits and payloads must still be checked. The original demonstration held in the right hand only. Left/both-hand recovery and the new joint planner have not been natively retested. Independent free single-link payloads only; bimanual retention of one object requires constrained planning. Read/reuse this published draft before inventing another recovery posture.

Read this source before selecting it. Recompute geometry from the current observation. Draft code is available for reuse and iteration; collection does not certify physical success. Keep failures and source hashes when adapting this program.
