## 一、核心进展一页总览（Executive Summary）

1. **多模式长程规划基准套件（`scheduling_v1` T1–T6）构建与验收完成**：
   - 从单一“设备计时等待重叠”扩展到涵盖 **时间并行掩蔽（T1–T3）** 与 **零等待（`0 s`）纯空间双向回程配货（T4）、单调工具洁净度状态机与闭柜盲盒补货（T5）、有限缓冲区非单调腾挪交换（T6）** 共 **6 个冻结场景长程任务**（定义见 [task_designs/scheduling_v1/README.md](../task_designs/scheduling_v1/README.md)）。

2. **Benchmark 与 Harness 严格解耦 + 三大 CLI 控制器统一接入**：
   - **Benchmark 侧**对所有方法固定不变：补齐床垫局部垂向射线落点、休眠刚体 `OnTop` 几何兜底、闭柜内部隔板自动绑定、抹布脏污度公开事实回执（`tool_cleanliness` v2）及连体台面子网格合并（`r3` 契约）。
   - **Harness 侧**全部做成默认关闭的显式命令行开关：升级同原语防早退守卫（`Finish Guard` v3）、选点局部放大回显（`Click Echo`）、渐进式轻量程序调度契约（`schedule_plan` v3），并新增 **`ClaudeAdapter`（`Claude Code CLI`）** 与 **`AgyAdapter`（`Antigravity CLI` + `bwrap` 隔离 + `<=9.6 KB` 自适应 WebP 内联重编码 + 连续不扣步报错熔断器）**。
3. **跨模型档位、跨 CLI 全量六项指标实测验证（累计 >90 个闭环回合 + 240 次静态盲测选点）**：
   - **强模型 `gpt-6.1-sol (low)`（`Codex CLI`）**：在 T1–T3 上文字/程序调度将原地干等从 `180–480 s` 压至 **`0.0 s`**，节省 **`14.1%–31.7%`** 机器人时间并在 T2 将达成率从 `0.875` 推至 **`1.000`**；在零等待任务 T4 上压缩 **`18.6%`** 路程（`206.5 m -> 168.1 m`）；在非单调换位 T6 上破解基线死锁实现 **`100%`** 通关；在 T5 `r2` 上基线与程序调度双双 **`100%`** 通关（更干净的 `r3` 契约 12 回合复测正在远端 PRO 6000 运行收口）。
   - **强模型 `gemini-4-hydrogen-low`（`Antigravity CLI`）**：在 T1 上文字调度将机器人时间从 `1,181.3 s` 压至 **`715.8 s`（节省 `39.4%`）**、路程压缩 **`53.2%`（`69.9 m`）**，创跨模型最高效率；在 T6 上程序调度 **`26` 步、`354.0 s` 满分通关**；在 T4 上文字调度压缩 **`28.4%`** 路程并达 `0.933`（`14/15`）。
   - **弱模型静态选点盲测与闭环诊断（`gpt-6.1-terra`、`gemini-3.8-flash-low`、`claude-sonnet-5-5-low`）**：静态盲测确认 `sonnet-5-5-low`（`98.3%`）、`3.8-flash-low`（`95.0%`）与 `6.1-terra`（`95.0%`）单帧视觉选点均极强，淘汰坐标错乱的 `flash-lite`（`5.0%`）。闭环实验揪出并修复了 **`agy` CLI 10 KB 多模态离线转存致盲 bug** 与 **Anthropic API 单会话 600 张图像硬上限**，使 `3.8-flash-low` 从 5–7 步原地早退跃升至 250+ 步跨房长程执行（程序调度在 T1 省路程 `16.9%`，辅助设施在 T6 将达成率从 `0.529` 提至 `0.765`），精准定位出弱模型的下一阶段核心瓶颈为**超 100 步后的状态账本漂移**。
