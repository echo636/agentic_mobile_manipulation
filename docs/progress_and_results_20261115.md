## 一、论文核心贡献定位（路线 A + 路线 B 结合：严禁针对测试集写押题策略）

### 1.1 双层通用方法架构（底层通用感知记忆 Harness + 上层零假设通用时空代价图规划器）
我们的论文核心贡献**绝不是针对某个特定测试集或某几类题型的定制策略**（严禁在提示词、技能说明或规划工具参数中硬编码“遇到家电先开”、“用托盘装满再走”、“抹布从干净往脏擦”等题型口诀或专用字段），而是构建一套**模型无关、任务无关的双层通用具身智能体架构（路线 A + 路线 B 结合）**：

1. **底层（路线 A）：通用具身闭环感知与记忆 Harness（保证“做得对、不忘事”）**
   主打一套模型无关、任务无关的通用具身上下文与闭环控制设施，由四大核心机制构成：
   - **① 四向视觉锚定 + 选点局部放大回显**：四路固定机身视角同步观测锚定方向感，配合像素点击局部放大回显，消除细小物体与边缘透视点偏；
   - **② 空间/物体状态外部记忆压缩**：仅从公开动作回执与历史视觉观测自动抽取结构化外部记忆（去过的地点、见过的物体位置、容器开合状态、手部持有物与公开状态回执），并对远古全景图像做滑动窗口压缩（或滚动会话无损续跑）——统一解决超 100 步长程失忆、千万级缓存 Token 膨胀与单会话 600 张图像硬上限；
   - **③ 预期偏差自纠错 + 防同动作原地早退**：公开返回物理受阻因果归因（如未开门遮挡、门扇挡视线），拦截同一动作原地重复报错偷懒早退，促使模型在动作结果偏离预期时主动切换动作自纠错；
   - **④ 结束前逐项视觉核验**：在调用 `finish` 声明完成前，对照公开任务要求逐条核对已观测视觉与回执证据，杜绝长程尾段漏件与虚假完成。
2. **上层（路线 B）：零领域假设的通用前置条件与时空代价图规划器（保证“做得快、不死锁”）**
   - **彻底推倒重做写死电器和托盘的旧版 `schedule_planner`**：把早期先导实验中绑定 `timed_processes`（机器计时）与 `carriers`（托盘配货）的专用规划表彻底推倒重做，抽象为一个**零领域假设的通用前置条件与时空代价图规划器（General Precondition & Cost-Aware Task Graph Planner）**；
   - **只认物理世界通用的四个基本原语**：输入与内部表示只包含通用的**“状态变量、前置条件与后置效果、持续时间（及是否占用单手）、空间移动代价”**，不含任何特定任务名词或题型规则；
   - **从同一个通用图搜索中自然涌现多模式高效调度**：在统一的带约束偏序任务图上最小化总完工时间与空间移动代价，让**异步等待并行、跨区顺路合并、最少状态重置排序、有限空间无死锁借位腾挪**全部从同一个通用图搜索里**自然涌现**。
3. **三级通用消融阶梯 × 双层固定评测基准（试卷与考生严格隔离）**
   - **三级考生阶梯**：**第一档（裸模型最小基线）** $\rightarrow$ **第二档（+ 路线 A：通用具身感知记忆 Harness）** $\rightarrow$ **第三档（+ 路线 A + B：底层通用 Harness + 上层零假设通用时空代价图规划器）**；
   - **双层固定试卷**：同时在 **① 原版 BEHAVIOR-1K 长程任务集**（证明在完全未定制的原生基准上全面提完成率、提效率）与 **② 多模式自建规划难任务集（T1–T6 已建成，T7–T8 扩建中）**（定义见 [task_designs/scheduling_v1/README.md](../task_designs/scheduling_v1/README.md)，理论规范见 [多模式规划难任务构造规范](multi_mode_planning_benchmark_design_20261115.md)）上开展跨模型家族对比。

### 1.2 前期先导摸底实验的核心发现（为什么必须走“路线 A + 路线 B 结合”）
在正式开发路线 A 的外部记忆压缩与路线 B 的零假设通用代价图规划器之前，我们先通过一套**先导摸底实验**（累计 >90 个闭环物理仿真回合 + 240 次静态视觉盲测）验证了基准潜力与现有组件的真实短板：
- **验证路线 A 基础护栏对弱模型的托底作用，并定位百步失忆瓶颈**：开启基础操作护栏后，弱模型 `gpt-6.1-terra` 首次在 T5（42 步）与 T6（25 步）实现 **`100%` 通关**（裸模型最小基线为 `0%`）；修复图像离线转存问题并开启基础护栏后，`gemini-3.8-flash-low` 从 5–7 步原地早退跃升至 250+ 步长程执行，清晰暴露出**超 100 步后的容器—物品状态失忆**与 Claude 模型的**单会话 600 张图像上限**——直接指明路线 A 必须补齐“空间/物体状态外部记忆压缩 + 结束前逐项视觉核验”。
- **验证多模式基准的物理优化空间，并暴露初版专用工具的泛化局限**：在 T1–T3 等待重叠任务上，`gpt-6.1-sol` 先导统筹组原地干等全部归零（`0.0 s`），节省 **`14.1%–31.7%`** 机器人时间并在 T2 将达成率推至 **`100%`**；`gemini-4-hydrogen-low` 在 T1 **省时 `39.4%`、省路 `53.2%`**；在零等待受限台面换位 T6 上，两款强模型均破解基线死锁实现 **`100%` 通关**。与此同时，初版行程工具因写死“机器计时”与“单向载具”字段，在 T4（三房双向置换）与 T5（工具状态重置）上收益受限——直接确立了路线 B **“彻底推倒重做专用 `schedule_planner`，升级为零领域假设通用前置条件与时空代价图规划器”**的核心动机。
