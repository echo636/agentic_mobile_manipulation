# 宏观导航与操作小脑

`target_locked_local_v1` 是 RGB 执行器的新默认协议。大脑选择任务顺序、宏观路线、目标像素与操作；一次 manipulation `act` 内，小脑准备局部站位并执行该操作。它沿用私有仿真几何和理想抓放执行器，不是 Startlux 或真实机械臂 IK 控制。

## 调用方式

1. 大脑先检查当前四路 RGB。目标看起来就在附近、且能可靠选中时，直接调用 `grasp`、`open`、`place_inside` 等操作；这也适用于初始画面，不以先调用 `navigate_to` 为前提。只是不确定精确距离或最佳站位时，让操作小脑检查和调整。
2. `navigate_to` 用于明显较远的目标、跨区域移动、探索/重新找到无法辨认的目标，或根据执行反馈选择新的宏观接近方案。导航后先检查全部四路图像；只要近处目标可选，就转入操作，不继续为了居中、转向或靠近一点而导航。目标在一路图像中被裁切时，先检查其他视角；四路都无法可靠选中才调整观察位置。
3. 小脑依次锁定目标、检查操作前提、检查可达性与可见性、选择局部站位、沿路径移动、重新检查、执行原子操作和验证结果。
4. 大脑收到一次结果和一组新的四路 RGB。内部移动不增加大脑对话轮次，不逐帧发送图像，也不占用额外的 agent act/look 次数；实际控制步、内部尝试和移动成本单独记录。

`initialize.control` 声明实际协议。`MAS_LOCAL_MANIPULATION=0` 保留旧的 `explicit_navigation_v1`，适合对照试验；运行记录同时保留该设置。旧实验使用冻结源码，不受开发目录修改影响。

这是大脑的动作选择规则，不是取消碰撞、操作前提或局部预算检查，也不保证可见目标一定能操作。目标过远时小脑仍返回 `needs_macro_navigation`，局部搜索失败仍按原类别交还控制。模型不需要也不能从隐藏几何获得精确距离；看得见但明显远处的目标仍应先宏观导航。系统提示、`act` 工具说明、执行 skill 和目标分解的 L3 规则共同表达该顺序，避免“先接近再抓取”的旧模板覆盖局部接管协议。

## 目标与权限边界

当前图像中的一次点选通过原有私有深度投影绑定对象和具体 link。选中表面点保存为 link 局部坐标，移动之后重新计算其世界位置，不重新解释旧像素，不选择其他同类物体、容器或层板。对象/link 消失或点位移动超过 25 cm 时交还控制。锁定仅在当前 act 内有效，下一次 act 仍需要最新 RGB 的选点；本版不提供历史目标句柄或 ROI 检索。

手占用、空手、关闭容器、不支持的状态或关系、明显不兼容的材料工具，优先作为操作前提错误返回，不为这些错误盲目导航。放置采样失败和后验失败不触发自动换站位重试。尤其不能靠导航修复盘子大于冰箱可填充容积的问题。

局部可操作性包括：原有 1.4 m XY 作用范围、四相机视锥及场景射线、自遮挡、底盘与携带物碰撞范围。新站位以 1.25 m 为优选范围，留下距离余量；它不是机械臂关节空间可达性的保证。只调整实际存在的底盘 XY 和 yaw，不虚构俯仰相机或上下移动能力。

理想抓取前，用完整载荷闭包预测抬高 18 cm、收近底盘及随后离开的路线，实际抓取沿同一条已检查路线分步执行。此预检不移动任何物体；载荷使用实际高度检查桌面、环境和机器人碰撞。抽离初始支撑时仅允许已有接触逐步减少，必须在抬升终点完全脱离；新接触会拒绝。

开关门前事务性采样关节运动，检查门扫过的空间及目标状态下的离开路线；不推进物理时间、env 控制步、指标或录像。预演无论成功、失败或取消都恢复场景、粒子和随机状态。实际操作使用同一组已检查的目标关节值，避免重新随机选择开门方向。

实际操作后重新检查离开能力；受困时在剩余预算内尝试接触递减的短退让或前向局部移动。初始姿态已重叠时也可尝试同一受限退让。恢复不重复已完成的原子效果。仍未获离开证明时公共结果明确标记 `operation_committed=true`、`recovery_required=true`，由大脑检查当前 RGB 并选择新的接近方案；不会自动关门、丢下物体或改变任务计划。

## 有界执行

默认每次 act：以调用起点为中心半径 2 m、累计移动不超过 4 m、最多 3 次换站位、最多 2 次原子尝试、600 个 env 控制步、1200 个采样物理步、300 秒墙钟。候选站位采样覆盖配置半径，并交错近、中、远距离及两侧候选，避免短预算只检查近处；1.25 m 只影响排序，硬作用范围统一为 1.4 m；局部区域的中心不会随机器人移动而重置。目标点的 XY 距离超过 3.4 m（2 m 局部半径加 1.4 m 操作范围）时交回宏观导航；进入范围仅允许尝试，不保证可达。候选规划有独立的 12 秒预算，每条路线先用 2 秒，至多给一个已通过几何检查但搜索未完成的候选额外 4 秒。搜索耗尽返回 `local_adjustment_exhausted`，不声称已证明不可达。既有更小的调用预算、取消和 episode deadline 始终优先。每个底盘命令在位置 setter 前检查局部范围；规划连接和搜索状态也不能离开局部区域。

携物抬升和收拢以 0.5 m/s 在实际 env 控制步中执行，每段复查完整载荷扫掠体。收拢路线至多 2 m，执行前确认剩余 act 步数足够；无法收拢时，只能在抬升姿态本身也有离开证明的情况下抓取。执行中环境变化导致检查失败时，停止并保留已有抓取关系。它仍是理想物体姿态控制，不代表真实手臂 IK。底盘和载荷分别保留碰撞轮廓，载荷按真实高度细分占用层，避免把已抬离桌面的盘子与较低桌面合并。脱困检查按实际高度连接障碍区域，不能用不同高度的新接触抵消旧接触。

显式 `look` 的底盘旋转使用与导航相同的当前碰撞层和完整旋转扫掠检查，只允许原地转动；受阻返回 `look_rotation_blocked`，不自动走绕路。观察四相机本身仍然不移动机器人。导航反馈额外区分地面点旅行、选中表面已可见且在作用距离内、仍需要更近接近；只有随后实际操作的小脑检查才能确认该操作可执行。

局部协议下，宏观物体接近优先搜索 1.25–2 m 的距离带，低目标依据相机高度、俯角和安装半径选择更远的观察站位，避免把有限可见性检查用在目标落出画面下沿的过近位置。候选仍需通过实际视锥、遮挡、进出与完整路径检查；距离带不是免碰撞或可操作保证。`within_local_range` 仅说明目标进入小脑接管距离，随后由操作自行检验站位。地面点旅行与旧显式协议保持原有目标语义。底层占用缓存只按不同高度保存一次；多个机器人/载荷轮廓共享同高度占用图，抓前预测和抓后切换只更新实际变化的物体区域。

没有进展、已访问过的站位和重复无效尝试受到限制。只有未改变世界的 `out_of_reach` 可以进入有限恢复；其他原子错误保留原类别。公共反馈只包含协议、有限尝试计数和动作级状态，私有坐标、对象 ID、碰撞图和 evaluator 信息不进入大脑上下文。

| 返回 | 大脑应做什么 |
| --- | --- |
| `needs_macro_navigation` | 目标太远，选择更近的宏观接近位置，再在新 RGB 中选目标 |
| `local_adjustment_blocked` | 局部区域内没有找到安全可操作站位，重新评估路线或任务前提 |
| `local_adjustment_exhausted` | 局部预算耗尽，根据当前 RGB 决定明显不同的宏观方案 |
| `target_changed` | 目标身份/表面跟踪失效，重新观察并选点 |
| `container_closed`、`sampling_error` 等 | 处理对应操作前提或几何问题，不重复微调导航 |

## 证据与比较

`local_manipulation.jsonl` 的子阶段带 `parent_request_id`，记录目标绑定、候选拒绝原因、内部路线、尝试、错误和完成状态；连续视频仍记录实际运动。外层 request ID 缓存保证网络重试不会再次执行整个操作。局部执行器不调用全任务 evaluator，也不把工具成功当成整任务成功。

本次同时修正旋转碰撞检查：长转动由与短转动相同的整数角度区间掩模取并集，避免“整段规划通过、其中一步碰撞拒绝”的离散化不一致。原捡垃圾记录的 CPU 地图重放已显示整段和失败小步一致拒绝；这不等于真实任务已通过。

验证记录位于工作根目录 `operations/local_manipulation_20261020/`。CPU 状态机、目标锁定、真实 adapter 控制循环夹具和历史地图重放是分开的验证层级。真实模拟器与自主任务的结果必须单独记录，比较时同时报告大脑调用次数、内部移动/尝试、时间、视频和独立任务成功率。

2026-10-20 站位、携物及开门撤离修复的分层验证记录位于 `operations/local_navigation_repair_20261020/`；CPU 回归、真实动作与自主整任务结果分开记录。
