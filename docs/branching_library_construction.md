# 双卧室与共用书柜：构建验证

2026-10-20 将[依赖设计](long_horizon_dependency_design.md)落成了独立的
[schema 3 配方](../task_designs/constructed_branching/bedroom_shared_library_branching_v2.json)。
配方由 `scripts/compile_branching_bedroom.py` 生成；不修改原四个冻结任务。

## 场景和任务

采用 `house_double_floor_upper` 的两个卧室和公共区。每房 6 本书、6 件玩具，
公共矮书柜起初摆放 6 个笔袋；两房地面、两张暂存台和书柜均有原生 dust 状态。
吸尘器与护理刷各有归还位置，4 盏任务台灯初始开启。

书柜是原生 `bookcase/kmuacd` 资产，缩放后约 1.93 × 0.62 × 0.86 米。
任务使用其可触达的顶面放书，未实现逐格插书。两张黄色暂存台、绿色玩具归位台、
蓝色笔袋收纳台和灰色工具台仍是明确的固定任务设施。书、玩具、笔袋、灯和工具使用原生资产。
护理刷的原生 ParticleRemover 支持 dust；台面的初始灰尘由配方设置，不声称搬运会生成灰尘。

三个工作分支可以交错推进：A 房腾空后吸尘、B 房腾空后吸尘、公共书柜清空后去尘。
每房玩具仅依赖本房吸尘；归书还依赖公共书柜清洁。每房物品全部归位、暂存台清空后才能擦台，
两房与书柜均完成后才能关灯，最终检查关灯、工具归位和手空。

运行时显式图为 **15 个里程碑、17 条边、2 个分叉节点、3 个非最终 AND 汇合**，
最长路径含最终检查为 7 个节点。这些都是必做支路，尚未加入观察结果决定的可选支路。
额外 state guards 约束提前归位、提前清洁、提前关灯，以及已清洁表面再次变脏的情况。
历史正确不代替当前状态；最终条件必须同时满足。

117 次有效操作是条件账本：24 次地面到暂存搬运计 48，24 次归位搬运计 48，
6 次笔袋搬运计 12，两次吸尘、三次擦拭、四次关灯计 9。
不包含导航、观察、工具交接和失败重试，也不是实测最短轨迹。

## 实际验证

| 运行 | 结果和范围 |
| --- | --- |
| `build_library_r1` | 失败：原生固定家具模板缺少运行时加载器要求的速度字段；构建适配层补全缺失零速度，保留来源数据和已有速度 |
| `build_library_r2` | 场景及相机启动后的 49 条初态检查通过，已冻结 |
| `inspect_library_r2` | 独立恢复、真实截图、工具兼容性和书位几何检查通过；首个导航动作因旧出生点与 A 房地面物品重叠而失败 |
| `build_library_r3` | 在初始化阶段主动终止已被新布局取代的本项目任务，确认进程退出并清除其缓存；无任务通过结论 |
| `build_library_r4` | 出生点移至公共区，两门用 `Open(fully=True)` 初始化；场景和相机启动后的 49 条初态检查通过，已冻结 |
| `inspect_library_r4` | 独立恢复、初态、6 张实景截图、护理刷能力和 12 个书位检查通过；首次前往 `clutter0` 的普通导航未找到完整可行路线，尚未进入搬运阶段 |

r2 的 `Open=True` 仅采样到约 23° / 28°，不能证明门洞可通行。
r4 实测门角约为 120°，但是否能通行仍由普通导航执行器检查。
未改动导航或抓放执行器；固定家具导入补全位于任务构建适配层。
最新失败为 `navigation_search_exhausted: No checked complete route among bounded endpoint candidates`，
与 r2 的出生点重叠错误不同。最新参考只有 1 次导航尝试，0 次成功操作、0 个已完成里程碑；
不能据此声称任何清理分支或整个任务已物理跑通，跨房路线和实际装满书柜也仍未验证。

[查看 r4 的真实场景截图](http://10.76.5.241:8765/long_horizon_build_20261020/branching_library_v2/overview.jpg)。
截图由冻结初态渲染，拍摄不执行任务动作；人类检查相机不会作为策略观测输入。

CPU 检查覆盖三种合法交错顺序、玩具不被书柜清洁额外阻塞、提前归书后补救仍拒绝、
书柜重新变脏、暂存条件退化、提前擦台和跨房提前关灯。构建适配修复后运行 80 项相关测试，
其中 2 项跳过；最新 r4 配方的 9 项专门检查通过。CPU 检查不证明物理可执行。

**`benchmark_ready=false`**。尚未完成两种合法顺序的完整物理参考及三个物理负例验收，
也没有视觉自主模型成功记录。参考使用特权物体身份和普通 checked executor，不能称作真实机器人或视觉自主策略成功。
