# Architecture and experiment contract

```text
Task instruction + fixed instance + protocol + budgets
                         |
            Model policy / integration recipe
                         |
     shared tool catalog: observe, act, plan, memory, finish
                         |
              Harness (one episode owner)
       schema + revision + preconditions + budgets
                         |
               Backend interface
               /               \
     CPU contract fixture     OmniGibson
                              official symbolic primitives
                              ideal reachable-map navigation
                         |
             execution result + new observation
                         |
               plan / memory revision

Independent evaluator -> BDDL + official TaskMetric -> run record + HTML
```

The model's six tools are exposed identically through native Python and MCP. HTTP worker threads only submit queued jobs; the creating thread alone accesses the simulator. A transport timeout means outcome unknown, not cancellation. HTTP clients replay the same request ID to avoid double execution. MCP call IDs are generated by the proxy, so a fresh MCP call after a timeout is a new operation: callers must observe before trying again. Cross-process crash recovery is not claimed.

`revision` changes after every executor attempt, including partial failures. Validation rejections do not move the world. Observation reads do not call `env.step`. A plan can be revised as new facts appear; dependency cycles, unknown dependencies and invented action evidence are rejected. A done claim can still misunderstand an effect, so only the independent evaluator decides the final task result.

The action-step limit is enforced while consuming the official primitive generator. Internal synchronous sampling can still take wall-clock time between yields; the outer systemd timeout provides a process-level backstop. The simulator remains frozen while the model deliberates. Neither frozen deliberation nor ideal teleport timing is comparable to physical execution speed.

For every experiment retain configuration, source SHA and snapshot, dependencies, assets, task template and instance versions, host, interpreter, GPU UUID, PID/unit, output directory, all failures, model/controller trace and final evaluator result. Use new run IDs for changes; never overwrite a failed attempt with its repair.

Validation levels are deliberately separate: CPU contracts; real MCP transport with a mock; real symbolic primitives with a deterministic policy; real model plus real simulator; repeated fixed-task evaluation; official challenge-compatible physical evaluation. Passing a lower level does not imply passing the next.
