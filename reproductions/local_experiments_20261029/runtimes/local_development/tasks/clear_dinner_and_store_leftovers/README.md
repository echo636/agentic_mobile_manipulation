# 第三个长程任务：餐后清台与剩菜冷藏

目标是结束一次客厅用餐：剩菜分装冷藏、待洗餐具集中到水槽、空托盘归柜。所有子目标服务同一次清台。相比杂货任务的“搬入与卸袋”和热饮任务的“制作与摆台”，本任务测量**拆解承托关系、分流食物与餐具、同类多件核查，以及清空后归位**。

**版本：design_v1，2026-10-22；设计候选，尚未制作或加载仿真场景。** `problem0.bddl` 是原生谓词定义草案，不是可直接运行的已注册任务。未进行机制探针、模型回合或 benchmark 验收；不产生官方挑战成绩。后续按[构建流程](../../docs/long_horizon_task_workflow.md)先验证风险链，再冻结完整场景，不能把现有热饮或公开清台实例号直接当成本任务实例。

## 人类指令与场景

模型只接收 [instruction.txt](instruction.txt)、四路 RGB 和公开动作反馈。作者侧 BDDL、目标绑定、DAG、场景要求及独立评分不作为模型输入。

初态：客厅茶几上有一个托盘，托盘上有两只空杯和一个盘子；鸡肉、菠菜和茶匙放在盘上。厨房台面有两个空保鲜盒；厨房水槽为空，冰箱和餐具橱柜关闭。食物是可抓取的刚体，不涉及液体、清洗、加热、盒盖或食物切分。两盒须分别装鸡肉和菠菜，但不指定盒子身份。完整对象和初态约束见 [scene_requirements.json](scene_requirements.json)。

先复用热饮任务的 `house_single_floor` 房间布局作为候选，复用公开 `clearing_table_after_dinner` 的食物/保鲜盒语义；这不意味着这些资产已经在同一实例中加载或能适配该布局。真实资产型号、位姿、房间绑定、碰撞、门状态和场景哈希均待探针确认。先检查厨房是否存在可用水槽及足够大的柜内空间。

## 目标与独立评分

计划采用 **custom_native_bddl**，`official_task_success=null`。原生谓词在最终物理状态独立评分；不引入热饮专用高层状态，也不根据动作日志中出现过成功放置来累积整任务成功。

11 项作者侧诊断目标如下。前四项必须来自同一个合法绑定，不能把两个分支中分别最好的结果拼接成成功。最终通过须整份 BDDL 为真。

| 编号 | 终态证据 | 初态要求 |
| --- | --- | --- |
| 0 | 鸡肉在其分配的保鲜盒内 | 鸡肉在盘上 |
| 1 | 菠菜在另一个保鲜盒内 | 菠菜在盘上 |
| 2–3 | 两个保鲜盒分别在冰箱内 | 两盒均空，均在厨房台面 |
| 4 | 盘子在水槽内 | 盘子在托盘上 |
| 5–6 | 两只杯子分别在水槽内 | 两杯均空，均在托盘上 |
| 7 | 茶匙在水槽内 | 茶匙在盘上 |
| 8 | 托盘在厨房餐具橱柜内 | 托盘在茶几上 |
| 9–10 | 冰箱、餐具橱柜分别关闭 | 均关闭，须经取放后复核 |

定义用两个完整 OR 分支接受两个盒子的身份交换。候选场景限定一个符合用途的餐具橱柜；若实际布局还有其他符合指令的厨房橱柜，冻结前必须扩展合法绑定，不能仅因选择另一合理柜子而判错（GROC-002）。水槽同理。用原生 `Inside` 验证盒内食物与盒体入冰箱，不假定搬运天然维持嵌套关系。

所有指定物品都有最终目的地，“茶几清空”由这些对象的最终去向实现，不另加未定义的全屋清洁或隐藏垃圾目标。两个盒内必须各有一种指定食物；两食物同盒、食物留在盘上、只冷藏一个盒子均失败。装载餐具到水槽不代表已经洗净。

## 真正依赖与可交错规划

[partial_order.json](partial_order.json) 是作者侧**终态完成依赖图**，不安装为时间门控评分器。它表达哪些义务完成后才能称某分支已收尾，不强制每个动作的时序。

- 食物从盘子分离、分别装盒，盒体入冰箱后还要保持内容关系，才能完成剩菜冷藏。
- 盘子和托盘的最终归位不能遗留上层食物或餐具。拿起盘子/托盘做成组运输、先暂放再拆解均合法；不要求必须在客厅先卸完再搬。
- 两只杯子、茶匙、剩菜可以交错处理。暂放的位置及水槽内摆放顺序不评分。
- 最后两个关闭目标只判断终态，不以曾经关过门替代。初态已经关闭不等于全过程中完成了收尾。

该任务没有时间窗口，不强制冷却、密封或先洗再放。单手操作时，为开门而暂放是执行协议产生的真实约束，不额外添加物品暂放位置目标。

## 最小探针与验收

先执行 [validation_plan.md](validation_plan.md) 中的两条高风险链：食物→盒→携盒过门→冰箱；上层餐具移除→托盘归柜。两链分别验证真实 RGB 可发现、显式接近、动作、关系保持及独立评分，再制作完整场景。若嵌套食物、托盘资产或柜内尺寸不可行，修订场景或任务版本，保留失败，不通过移除目标提高分数。
