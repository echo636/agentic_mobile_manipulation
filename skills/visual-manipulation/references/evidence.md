# Evidence for completion

- Current RGB and action feedback override unsupported notes. Earlier observations remain useful when object continuity is supported.
- Match the intended object and relation to the reported effect. Navigation success establishes approach; toggling establishes a switch change; neither verifies later manipulation or processing.
- Hidden contents can be supported by observed placement and undisturbed continuity. Recheck when handling may have changed them.
- Before finish, account for every required item, relation and device state. Use the last returned views; an extra observation call is not required.
- Notes, plan completion and local action success are not the private whole-task evaluation.
